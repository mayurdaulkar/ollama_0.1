# 33. Glossary

**Embedding:** Numerical representation used for semantic retrieval.

**Chunk:** A smaller document segment indexed for retrieval.

**Hybrid search:** Combination of lexical and vector retrieval.

**Grounded answer:** An answer supported by retrieved evidence.

**Abstention:** Declining to invent an answer when evidence is insufficient.
